# Hi 👋

I work in cybersecurity with a focus on security operations, threat intelligence, incident response, and practical security engineering.

## What I Do

- **Security operations:** Triage alerts, investigate suspicious activity, support incident response workflows, and improve detection quality.
- **Threat intelligence:** Collect, enrich, and organize indicators and context to support faster investigations and more informed defensive decisions.
- **Threat hunting:** Use endpoint, network, and log data to identify suspicious patterns, validate hypotheses, and document repeatable findings.
- **Malware and phishing analysis:** Review artifacts, metadata, behavior, and infrastructure to determine risk and recommended response actions.
- **Security tooling:** Build scripts and small applications that automate repetitive analysis, normalize data, and make security workflows easier to use.
